# 🚀 Coddy Web Academy: Interactive 76-Module Developer Experience

An interactive web application inspired by **Coddy.tech** (`coddy.tech`), guiding developers from complete beginner to pro across **HTML5, CSS3, JavaScript (ES6+), and TypeScript**.

---

## 🌟 Coddy.tech UI & Learning Process

### 1. Coddy Split-Screen IDE Architecture
- **Left Pane (46% width)**: Interactive 4-step guided lesson stepper (`Theory` ➔ `Quiz Check` ➔ `Code Challenge` ➔ `Celebration`).
- **Right Pane (54% width)**: Active Code Editor with tabbed output panel (`🧪 Test Cases`, `💻 Console`, `🌐 Visual Preview`).
- **No disconnected tabs**: Reading theory and writing code live side-by-side at all times.

### 2. The 4-Step Guided Pedagogy
1. **Step 1: Theory & In-Depth Concept**: Clean typography, code snippets, visual comparison tables, and warning/tip callouts.
2. **Step 2: Active Recall Quiz**: Immediate check with instant color-coded feedback (`✓ Correct` or `✗ Incorrect`) and conceptual explanations before touching code.
3. **Step 3: Real Code Challenge & Multi-Test Suite**:
   - Specific requirements, constraints, and starter code.
   - Run via **▶ Run Code & Test** or `Ctrl+Enter`.
   - Discrete test cases with **Expected vs Output Diff Cards**.
4. **Step 4: Celebration & Next Lesson**:
   - Confetti burst, XP gem reward (`+50 XP`), daily streak protection (`🔥`).
   - Seamless one-click continuation to the next lesson.

### 3. Gamification & Progression
- 🔥 **Daily Coding Streak**: Duolingo/Coddy-style flame counter calculating consecutive days of practice.
- 💎 **XP Gems Counter**: Accumulates experience points across quizzes and tests.
- 🗺️ **Interactive Course Map / Roadmap**: Full vertical curriculum map with status nodes (`✓ Completed`, `⚡ Current`, `Upcoming`).
- 📄 **Active Track Switcher**: Switch freely between HTML5, CSS3, JavaScript, and TypeScript tracks.
- 🔤 **Dynamic Font Scaler**: Adjust between Compact, Standard, and Relaxed font sizes.
- 🎓 **Mastery Certificate**: Generate and print/save a personalized PDF certificate upon completing a track.

## 📚 76 Exhaustive Learning Modules

### 1. HTML5 Track (18 In-Depth Modules)
- **Beginner (1–6)**: Document Anatomy & Quirks Mode, Semantic Landmarks, Typography & Quotes, Hyperlinks & Hash Navigation, Lists & Description Lists, Responsive Images (`srcset`, `<picture>`).
- **Intermediate (7–12)**: Native Video & Audio with WebVTT Subtitles, Accessible Data Tables, Modern Forms Architecture, Native Constraint Validation API, HTML5 Canvas 2D API, Inline SVG.
- **Advanced (13–18)**: Web Accessibility (a11y) & ARIA Specification, Document Head & OpenGraph SEO, Native `<dialog>` Modals & Popovers, Custom Elements Lifecycle & Slots, Shadow DOM Encapsulation, Web Storage & PWAs.

### 2. Modern CSS3 Track (18 In-Depth Modules)
- **Beginner (1–6)**: The Cascade Algorithm & Specificity, Modern Pseudo-classes (`:is()`, `:where()`, `:focus-visible`), Box Model Decoded & Margin Collapsing, Display Formatting Contexts, Modern Units (`rem`, `dvh`, `clamp()`), Typography & `font-display: swap`.
- **Intermediate (7–12)**: CSS Positioning & Stacking Contexts (`z-index`), Flexbox 1D Layout System, Flexbox Item Sizing Mathematics, CSS Grid 2D Foundations, Auto-Fit Responsive Grids, Responsive Strategies & Media Queries.
- **Advanced (13–18)**: CSS Custom Properties & Multi-Theme Architecture, Transitions & 3D Transforms, Keyframe Animations, Container Queries (`@container`), The Relational Parent Selector (`:has()`), Native CSS Nesting & Subgrid.

### 3. JavaScript ES6+ Track (18 In-Depth Modules)
- **Beginner (1–6)**: Variables, Scope & Temporal Dead Zone (TDZ), Primitive Data Types & Implicit Coercion, Control Flow & Error Handling, Modern Arrow Functions & Rest Parameters, Objects & Optional Chaining (`?.`, `??`), Modern Array Transformations (`map`, `filter`, `reduce`).
- **Intermediate (7–12)**: DOM Manipulation & Selection, DOM Event Propagation & Delegation, Scope, Execution Context & Closures, Asynchronous JS: Callbacks to Promises, `async/await` & Concurrent Combinators (`Promise.all`), Fetch API & AbortController.
- **Advanced (13–18)**: JavaScript Event Loop & Concurrency Model, Prototypes, Inheritance & ES6 Classes (`#` private fields), Functional Programming & Currying, Iterators & Generator Functions, Memory Management & Memory Leaks, Performance: Debouncing, Throttling & Web Workers.

### 4. TypeScript Track (22 In-Depth Modules)
- **Beginner (1–7)**: Foundations & Mental Model, Primitives (`any`, `unknown`, `never`), Arrays & Tuples (`as const`), Function Signatures, Type Aliases vs Interfaces, Union & Intersection Types, Type Narrowing & CFA.
- **Intermediate (8–15)**: Generics Foundations, Generic Constraints & `keyof`, Advanced Interfaces & Index Signatures, OOP & Classes, Custom Type Guards (`is`), Built-in Utility Types deep-dive, DOM typing, strict `tsconfig.json`.
- **Advanced (16–22)**: Conditional Types, `infer` pattern matching, Template Literal Types, Mapped Types & Key Remapping (`as`), Recursive Types (`DeepReadonly`), Branded & Nominal Types, and Result Architecture.
